# Legacy autonomous bot snapshot

at the start of the minimal-autonomous reset on 2026-08-23. It includes all
uncommitted spatial-authority and physical-model changes based on commit
`7eb6d6367c1d0cd6bd5f7621f15031b06a8307d9`.

The files are reference material only. The NBlood build does not compile this
directory, and the active bot must not include or call into it.
